Why Students Use Syncly

Built to remove manual calendar entries and ensure you never miss an assessment window

⚡

Automated Calendar Sync

Instantly extracts test timings, venues (CLT, ICSR, SAC, RMN, CRC), and meeting links directly into your connected Google Calendar account.

💼

Placement Vault

Maintains an organized library of registered companies, portal URLs, and attachments so you have all links ready on interview day.

🔒

Zero Data Collection

Processes notifications purely on your local Android device. Never reads private chats, never accesses message history, and has no tracking.

⏰

Proactive 60-Min Alarms

Automatically configures notification alarms 60 minutes before your test or talk so you can join portals and halls on time.

✨

Intelligent Conflict Avoidance

Deduplicates announcements to prevent cluttered calendars when the same notice is posted across multiple groups.

🚀

Battery & Performance Friendly

Zero continuous background polling. Runs lightweight event listeners only when a WhatsApp notification arrives.

3-Step Quick Setup

Simple installation on any Android phone (No root or developer mode required)

1

Download the APK

Tap the download button above. If prompted to allow unknown apps, tap Settings → Allow from this source.

2

Grant In-App Access

Open Syncly and grant Calendar and Notification Access so it can read placement alerts.

3

Connect Your Account

Tap the account chip at the top of the Home screen to select your preferred Google Calendar email. You're all set!

Release & Version History

Stay up to date with the latest improvements, fixes, and feature additions

v1.1.0 (Build 11) Latest Release
October 2026
  • Instant Background Calendar Sync: Integrated READ_SYNC_SETTINGS and WRITE_SYNC_SETTINGS permissions to guarantee immediate Google Calendar synchronization without requiring users to manually refresh accounts in phone settings.
  • Expedited Dual Authority Sync: Enforces automated master sync and triggers expedited refresh on both CalendarContract.AUTHORITY and com.google.android.calendar.
  • Fixed Calendar Provider Exception: Eliminated restricted VISIBLE column writes that caused calendar insertion failures on select Android versions.
  • Strict Casual Chat Filtering: Suppresses casual questions, greetings, and conversational chatter from being parsed into calendar events.
  • Source Whitelist Enforcement: Completely removed and excluded non-official sources (such as Aakhari Prayatnam).

🛡️ Built with Student Privacy as Top Priority

Syncly uses Android's official NotificationListener API to read incoming previews only. It has no backend server storing your messages and operates completely offline and on-device.
